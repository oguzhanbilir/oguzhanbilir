# LoL Match Assistant

While a League of Legends match loads, there's little time to study the other team. I wanted something that does it for me.

## What I built

You enter a Riot ID, it finds the live match and compares both teams.

## Key features

- Lane matchups, item suggestions and risks
- Strategy for each phase of the game
- Rule-based analysis from champion and matchup data in JSON
- Pre-game information only; it never touches the game client

## Stack

Python, FastAPI, React, Riot Games API

## My role

A personal project. I built the backend, the rules and the React front end.

## Outcome

Works with a Riot developer key, which has to be renewed every 24 hours.
